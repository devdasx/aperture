Every line. In the open.

The repository isn't a marketing excerpt — it is the shipping product. Read it, build it, and confirm that what's in the App Store is exactly what's on GitHub. For a wallet, openness isn't a philosophy. It's a security control.

Open license  ·  Swift 6  ·  github.com/devdasx/aperture

Reproducible, byte for byte.

Open code alone proves what could ship. A reproducible build proves what did. Compile the source yourself and the output matches the App Store binary — so the code you audited is provably the code you run.

01 · Clone
Pull the repository — the whole app, its tests, and its build instructions. Nothing is held back in a private overlay.
02 · Build
Compile with the pinned toolchain, following the reproducible‑build instructions in the repo. Same source, same toolchain, same bytes.
03 · Compare
Check your build against the App Store binary, byte for byte. If a single byte differed, anyone on Earth could catch it — publicly.

Fully open source, and reproducible. No other major multi‑chain mobile wallet offers both.

Closed code asks for trust. Open‑but‑unverifiable code asks for almost as much. Aperture asks for neither — the math checks, or it doesn't.

A codebase built to be read.

Auditable isn't just public — it's small, strict, and disciplined enough that reading it is actually possible.

Two dependencies, on purpose

Trust Wallet Core for key derivation, GRDB for storage — both open source, both battle‑tested. The project's written rule: the default answer to a new dependency is no. Less code from strangers means less to audit.

Swift 6, strict concurrency

Built on the current toolchain with complete concurrency checking — whole classes of data races are refused at compile time, not discovered in production.

Tested where it counts

Key derivation, signing, storage, and reset paths are covered by a public test suite — including a test that fails if a new credential store is ever left out of the delete‑means‑delete wipe.

What openness buys you.

Not a badge on a website — concrete, usable guarantees.

Audits by anyone, anytime.

No NDA, no permission, no waiting for a paid firm's PDF. Every researcher, competitor, and skeptic on Earth is a potential reviewer — permanently.

No hidden endpoints.

Every server the app can talk to — every Electrum host, RPC provider, and price API — is declared in the source. What the code can't do, the app can't do.

A history you can read.

Every change to the app — and to the privacy policy and terms you just read — is version‑controlled in public. Nothing is edited quietly.

Credit given, licenses kept.

The app's own license and its third‑party notices — down to the icon set — ship in the repository, in plain sight, the same way everything else does.

Read it. Build it. Verify it.

The strongest claim a wallet can make is one it doesn't have to make at all — because you can check.
